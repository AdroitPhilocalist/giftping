## Cursor bug (real cause)
Over buttons and fields the robin drifted away from the pointer. Cause: the "interactive" state used the CSS `scale` property on the same element that moves by `transform: translate()`. Individual transform properties (`scale`, `rotate`, `translate`) are applied on the OUTER side of `transform`, so scaling the element scaled its translation too — the robin was displaced by 22% of its distance from the top-left corner (and 20% the other way when pressed). Fix: the mover is now a plain translate-only wrapper; scale and the left/right flip live on an inner element. Verified numerically (robin centre == pointer position over the cart icon at the far right of the header). Also: over text fields and dropdowns the robin now fades out and the native cursor takes over (previously both showed at once).
