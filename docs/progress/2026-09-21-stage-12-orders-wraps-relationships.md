# Stage 12 (slice 6) — wrap styles, My orders, shop by relationship, account hub

## Decisions
- **Wrap style: built.** The five delivered swatches became a real choice at checkout (Classic Green, Blush Rose, Royal Blue, Premium Gold, Ivory & Sage). It is deliberately *cosmetic*: one flat per-order wrap fee whatever the style, so no pricing, no `place_order()` change and nothing the totals check could disagree with. Stored as `orders.gift_wrap_style` (migration `20260921140000_gift_wrap_style.sql`, CHECK pins the five ids, no client write path — orders have no UPDATE policy). The server validates the id (zod enum from `lib/commerce/wrap-styles.ts`) and writes it with the service role right after the atomic order insert; if that write fails the order is still fine (logged). Shown on the customer's order summary, the vendor's order view ("Gift-wrap this parcel in Blush Rose (blush pink with a rose-gold ribbon)") and the admin order page.
- **Shop by relationship** (`lib/relationships.ts`, `components/home/RelationshipCards.tsx`, `/gifts-for/[who]`): five portraits → real product filters over tags vendors already choose (parents/colleagues/kids use recipient tags; partner → anniversary, friends → birthday occasions — there are no partner/friend recipient tags). A test pins every filter to a tag vendors can actually pick.
- **My orders** (`/orders`): list with thumbnails, headline status, mini progress bar, pagination; navbar "Track Order" and account menu now lead here. **Account** page rebuilt as a hub (greeting + five tiles); the stale "order history arrives with payments" text is gone.
- Branded 404 (`app/not-found.tsx`) and error page with the robin. `Robin` got a `priority` prop for above-the-fold use.
- New optional artwork slots wired: `world-boutiques`/`world-atrium` (and the occasion worlds) on the /mall destination cards; `auth-welcome` as the sign-in/up side panel. Prompts appended to `docs/design/asset-prompts.md` (items 18–19).
